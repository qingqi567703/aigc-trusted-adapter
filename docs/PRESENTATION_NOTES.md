# 课堂汇报讲解稿（匿名）

建议先看报告第 5–6 节和以下讲解，再用 DEFENSE_GUIDE.md 核对关键概念。以下是可讲述的内容，未声称你已经讲解或完成答辩。

1. **问题在哪里。** 输入是一段文字和一张边缘条件图，模型据此生成照片。如果用户画错了几条线，模型可能把错线画成真实物体。我们研究用户已经标记了不可靠区域时怎样减轻这个问题，而不是研究如何自动发现错误。
2. **主论文与实际训练。** 主论文是 AAAI 2024 的 T2I-Adapter。我们固定 SD1.5，只微调约 77M 参数的适配器。原基线和改进版都训练了 1,500 步，有日志和检查点。我们自行实现训练循环，使用 Canny 边缘，不能称为作者全量实验的等价复现。
3. **模型与梯度路径。** 适配器把条件变成四个尺度的特征，注入扩散 U-Net。U-Net 权重不更新，但损失仍经过它向适配器传播梯度。绿色模块更新，灰色骨干冻结；VAE 缓存保存后验参数，训练继续采样。
4. **我们的局部修改。** 先将条件乘可信度 R，再在特征端乘带有限学习调整的 R。训练对同一目标构造两种扰动，共享噪声，在可信区域约束预测一致。推理只输入一份条件。空间门控已有先行工作，我们检验的是这些具体设计是否必要。
5. **实验协议。** 8,000 训练图、400 开发图；冻结测试前 400 张。四主配置各两个训练种子，加两个种子 42 消融，共十次微调。所有生成使用相同输入和噪声，共 12,000 张输出。可信度来自已知合成区域，这是实验边界。
6. **主实验。** 错误跟随提升量从原基线约 0.4522 降至预掩码 0.0739，再降至完整方法 0.0325。但原基线可信轮廓 F1 约 0.7081，完整方法约 0.6857；不能只讲错误抑制而略过布局损失。相对预掩码，错误跟随的配对区间支持降低，F1 差异区间跨零。
7. **简单基线与消融。** no_pair 与 fixed_gate 的错误跟随不比 full 差，各指标配对区间均跨零。学习门控和配对目标未显示稳定独立贡献。我们把这个结果保留下来，避免把输入可靠性信息和固定衰减的作用全部归因于复杂组件。
8. **相同输入对比，前两张。** 清单第一张钟楼仍有额外钟面；第二张桌面出现额外黑色小物体。错误控制抑制没有消除基础模型的幻觉。这两张不是筛选出的最佳案例。
9. **继续检查固定案例。** 第三张卧室差异较小。第四张冲浪中，原方法把额外笔画解释为杆或旗帜结构，预掩码和完整方法有所缓解，但单例无法证明 full 胜过 premask。四张均按固定测试顺序展示。
10. **证据边界。** FID-400 不与 FID-50K 比；两个训练种子也不足以代表所有训练随机性。共同排除 15 张被任意配置过滤的图像后，错误抑制仍存在，但 CLIP 微小优势不稳定。本轮只验证单骨干、合成边缘与外部给定 R。
11. **结论。** 实际完成训练、对照、消融、样例和可复现记录。数据支持显式可信度及特征衰减的作用，尚不支持两个学习组件都有效，更不能据此宣称顶会贡献。为节约时间，本轮停止追加训练；若继续研究，先验证真实手绘及不完美 R，再决定是否增加复杂机制。

若讲解时间较短，可压缩背景、资源和机制文字，优先保留“实际训练、预掩码强基线、两个指标的取舍、负面消融、固定成功与失败案例”这五条证据。不要说“错误概率降低约 93%”：这里的差值指标不是错误概率。
