# 成员分工与实际贡献说明（匿名版本）

本项目按一名真实课程成员准备。匿名版本不填写姓名与学号；AI 助手不计作第二名课程成员。

实际已发生的分工如下：

| 参与方 | 已完成工作 |
|---|---|
| 课程成员（匿名） | 提供课程文件与目标，确定时间和算力上限；提供本机资源；预约校内四卡服务器，配置平台公钥与访问条件；提供挂载路径和网络情况；决定优先缩短完成时间，并选择匿名报告。 |
| AI 编程助手辅助 | 文献与资格核查、方案设计、项目代码与离线资源准备、经授权的 SSH 操作、实际训练和评测执行、日志与检查点备份、统计分析、图表和报告初稿整理。 |

截至本文件生成时，不将“课程成员已独立完成全部编程、已逐行审阅代码、已完成答辩”等尚未发生的事项写成事实。课堂讲解和对提交内容的最终核对由真实课程成员完成。理解材料见 `DEFENSE_GUIDE.md` 与 `PRESENTATION_NOTES.md`。

本项目保留真实失败和不确定结论：完整方法降低了错误条件跟随，但可信轮廓保持未明确超过预掩码；学习门控与配对项的独立价值尚未证实。AI 辅助不改变这些证据边界。
