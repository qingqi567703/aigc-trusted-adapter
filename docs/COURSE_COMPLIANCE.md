# 课程要求与交付对应

依据用户提供的一页《生成式人工智能导论》期末作业文件逐条核对。这里记录完成证据，不代替教师的评分判断。

| 原要求 | 对应材料与实际状态 |
|---|---|
| 每组 1–3 人，提交实际贡献 | 一名匿名课程成员；`CONTRIBUTIONS.md` 明确 AI 辅助与真实成员已完成事项，未虚构另一名学生。 |
| 近三年正式 CCF A 类长文 | T2I-Adapter，AAAI 2024 主轨，38(5):4296–4304；DOI 与主轨清单链接见 README，上游正式元数据见 resources/upstream_source.json。 |
| 图像或音频生成 | 文字及边缘条件到 512×512 图像的扩散生成。 |
| 基线及改进实际训练或微调 | 10 次实际微调，每次 1,500 步；逐次 config、train.jsonl、status、检查点 SHA 可核查。 |
| 提出有明确动机的机制修改 | 输入可靠性预掩码、多尺度门控及配对去噪目标；不是仅改提示词或超参数。负面消融结果如实报告。 |
| 原方法对照及消融或诊断 | 四个主配置各两个种子；两个同种子消融；可靠性分组、图像配对 bootstrap 与安全过滤敏感性分析。 |
| 同输入生成对比 | 同一文本、原始条件、可信度、噪声种子；保存 12,000 张实际生成图。原方法按定义忽略 R；预掩码与完整方法共享 R。 |
| 完整配置、日志与检查点 | 轻量记录在 results/runs；10 个完整优化器检查点和全部样本已另行备份，见交付清单。 |
| 每人 6–8 页正文报告 | 匿名实验报告正文 7 页，参考文献另 1 页；正文覆盖要求的各项内容。 |
| 课堂汇报、每人理解并答辩 | 11 页横向 PDF 和讲解、问答材料已准备；真实课堂答辩由课程成员完成。 |
| 可访问 GitHub 仓库及 README | 仓库地址为 https://github.com/qingqi567703/aigc-trusted-adapter ，包含项目代码、完整 README、轻量运行记录和匿名 PDF。课程平台提交与课堂答辩由真实课程成员完成。 |

本轮复现是从公开权重出发的小规模生成微调，使用本项目 Diffusers 训练实现，未运行作者全量训练，也未逐层证明与作者原实现数值等价。报告明确写出这些差异。
